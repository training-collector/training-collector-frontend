# Training Collector Frontend

Кабинет тренера на React, TypeScript и Vite. Нужен Node.js 22.12+.

```sh
cp .env.example .env
npm ci
npm run dev
```

Сайт доступен на `http://localhost:20555`. В `.env` задаются `FRONTEND_PORT` и `BACKEND_URL` (по умолчанию `http://127.0.0.1:8080`). Браузер обращается к `/api/v1` на том же домене. Vite проксирует запросы к бэкенду.

`npm run build` проверяет TypeScript и создаёт `dist/`. Для статического хостинга настройте прокси `/api/*` на платформу. В Docker эту роль выполняет Nginx, а `BACKEND_URL` и `FRONTEND_PORT` задаются при старте контейнера.

```sh
docker build -t training-collector-frontend .
docker run -p 20555:20555 -e BACKEND_URL=http://platform:8080 training-collector-frontend
```

Адрес `platform` в примере должен разрешаться в сети контейнера.

## Vercel

Импортируйте репозиторий как отдельный проект Vite. Укажите `BACKEND_URL` в настройках окружения до сборки, например `https://api.example.com`. Используйте постоянный HTTPS-домен бэкенда без пути. Для Preview задайте адрес тестового бэкенда. При изменении адреса пересоберите проект.

Vercel собирает сайт командой `npm run build` и проксирует `/api/v1/*` и `/health`. После деплоя `/health` на домене сайта должен вернуть `OK`. Фронтенду достаточно одного адреса бэкенда.

### Работа в кабинете

Откройте **Упражнения**, чтобы найти опубликованное администратором упражнение по названию или описанию. Цели из общего справочника доступны в карточке подопечного.

В разделе **Подопечные** добавьте клиента. Во вкладке **Тренировки** выберите ранее добавленное упражнение из общего каталога. Для каждого подхода можно указать повторы или время, вес, отдых и RPE. Откройте запись, чтобы изменить подход, добавить упражнение, повторить тренировку или удалить её. **Замеры** показывают последние значения и датированную историю. В **Карточке** доступны редактирование, архивирование и удаление клиента.
